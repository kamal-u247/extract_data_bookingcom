# Future Plan Timeline

An append-only history of planning and implementation events for the `future_plan` branch.

Dates use the `D MMM YYYY` format. Every entry links to a plan ID in [FUTURE_PLAN.md](./FUTURE_PLAN.md).

| Date | Plan | Event | Status | Notes |
| --- | --- | --- | --- | --- |
| 3 Sep 2026 | FP-2026-09-03-price-extraction | Plan added | Planned | Define reliable, search-context-specific Booking.com price extraction. |

## Timeline rules

- Append one row when a plan is added, work starts, implementation is merged, or the plan is completed, cancelled, or replaced.
- Do not change earlier timeline entries. If information changes, append a later event that records the change.
- Include the implementation branch, pull request, or merge commit in the Notes column once it exists.
- Use only confirmed dates and events. Do not prefill future work or completion dates.
